# English Daily v13 — 教材載入與新舊備份相容修正版

- 介面版本仍為 **v13**。
- 載入舊版（只有 units、沒有 courses/courseId）的 JSON 時，自動補上 TOEIC Listening 教材分類，保留 50 部影片、歷史紀錄、每一輪複習日期及個人設定。
- Supabase 初次比對改為先轉換相容資料格式並對鍵排序。僅分類資訊或 JSON 欄位順序不同時，不再誤報雲端衝突。
- 如果雲端和本機真正有不同的進度，仍會暫停並要求手動選擇，不會擅自覆蓋。
- 更新 PWA 快取名稱；安裝後應確認 App 介面仍顯示 v13。

## 安全更新順序
1. 手機、電腦各自匯出 JSON 備份並另外保存，不要先按「上傳本機紀錄」或「下載雲端紀錄」。
2. 解壓縮這個 ZIP，將裡面的檔案放在 GitHub Pages Repository **根目錄**，覆蓋舊檔，完成 Commit。
3. 先用電腦一般視窗重整 App，確認「單元 → 教材」選單顯示 TOEIC Listening（50 部）。
4. 確認學習紀錄與手機相同後再觀察 Supabase 狀態。真正有差異時先比較備份，不要直接強制同步。
